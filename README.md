# Customer Churn Prediction Using Machine Learning

## Project Overview
Customer churn prediction is an important task in the telecom industry to identify customers who are likely to discontinue a service. This project uses Machine Learning techniques to predict customer churn based on customer details and service usage patterns.

The system helps telecom companies improve customer retention by identifying high-risk customers and taking preventive actions.

---

## Problem Statement
Customer retention is a major challenge in telecom industries. Losing customers directly affects business growth and revenue. This project predicts whether a customer is likely to churn using machine learning models, enabling companies to make data-driven decisions.

---

## Objectives
- Predict customer churn accurately
- Improve customer retention strategies
- Analyze important customer features affecting churn
- Compare model performance using evaluation metrics
